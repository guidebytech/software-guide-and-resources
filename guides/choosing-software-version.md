# Choosing the Right Software Version

Installing the correct software version can prevent compatibility problems and unnecessary troubleshooting.

## Check the Operating System

Before downloading an application, confirm which operating systems and versions it supports. Some applications provide separate packages for Windows, macOS, Linux, Android, or iOS.

## Check Architecture

On desktop systems, software may be available for different processor architectures. Use the version that matches your device when the publisher provides separate packages.

## Check System Requirements

Look for requirements such as:

- Supported operating system
- Processor requirements
- Memory requirements
- Available storage
- Required frameworks or dependencies
- Supported graphics hardware when relevant

## Stable vs. Preview Releases

Some projects provide stable, beta, preview, or development releases.

A stable release is generally the appropriate starting point for normal use. Preview versions can be useful when testing new features, but they may behave differently from a stable release.

## Use the Correct Source

Whenever possible, obtain software from the developer's official website, the operating system's trusted application store, or another distribution channel documented by the publisher.

Avoid downloading installers from unknown mirror sites when an official source is available.
