# Clean Uninstall and Reinstall

Reinstalling software can help when an installation is damaged, but removing an application does not always remove every setting or user-created file.

## Before Uninstalling

Identify anything that needs to be preserved, such as:

- Documents
- Project files
- Saved settings
- Templates
- Exported data
- License information
- Application-specific profiles

## Uninstall Normally First

Use the operating system's standard uninstall process or the software publisher's documented removal tool.

Restart the device if the publisher recommends it.

## Install Again

Download a current compatible installer from a trusted source and install the application normally.

Avoid installing multiple unofficial versions at the same time.

## Restore Data Carefully

If you backed up application data, restore only the files you actually need.

If the original problem involved corrupted settings, restoring every old configuration file may recreate the same problem.

## When a Deeper Cleanup Is Appropriate

Some applications provide official cleanup utilities for removing remaining components. Use those tools only when documented by the publisher and when a normal uninstall and reinstall does not resolve the issue.
