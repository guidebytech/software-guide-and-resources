# Software Installation Checklist

A few basic checks before installation can prevent many common problems.

## Before Installing

Check:

- The software supports your operating system.
- There is enough free storage.
- The downloaded installer is complete.
- Your system meets the documented requirements.
- You have the permissions required to install the application.

## During Installation

Read the installation screens instead of accepting every option automatically.

Pay attention to:

- Installation location
- Optional components
- File associations
- Startup behavior
- Additional software offers

Only select components you actually need.

## After Installation

Open the application and verify that it starts normally.

If the software requires an account, confirm that the sign-in process works before changing additional settings.

## If Installation Fails

Record the exact error message first. Then check the application's documentation for that error.

Avoid repeatedly running the same failed installer without identifying what caused the failure.
